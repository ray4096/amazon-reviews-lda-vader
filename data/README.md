# Data

The dataset is **not** included in this repository (it is several hundred MB).

1. Download *Amazon Reviews Polarity* from Kaggle: https://www.kaggle.com/datasets/kritanjalijain/amazon-reviews
2. Unzip and place `train.csv` here as `data/amazon_review.csv` (or change the path in the notebook).

The CSV has **no header row**; columns are: `polarity` (1 = negative, 2 = positive), `title`, `review`.
Original dataset description: see `DATASET_README.txt`.
